DeepHire — Архитектура и Data-Flow

AI-платформа подбора персонала на базе HH.uz. nginx (:8385) распределяет запросы между frontend (Next.js) и backend (FastAPI); backend работает с общим стеком shared-services на сервере (MongoDB, Redis, Qdrant, MinIO) и с внешними системами — HH.uz REST API, MCP-сервером (шлюз Cleverstaff) и Ollama/LiteLLM.

① HH.uz REST API — прямое подключение

hh_service.py напрямую ходит на api.hh.uz (OAuth-токен, /resumes, /resumes/{id}) — глобальный семафор ≤3 параллельных запроса, кеш поиска в Redis. Используется в «Smart Rematch».

② MCP-сервер — 172.31.174.11:8765/mcp

Отдельный шлюз (JSON-RPC поверх HTTP), даёт два инструмента: search_candidate_hh (проксированный поиск по HH.ru) и search_candidates (собственная база Cleverstaff). Используется в «Поиск через MCP» и в фоновой синхронизации Cleverstaff.

Шаги

    Примечание: MongoDB, Redis, Qdrant, MinIO и Langfuse запускаются централизованно на сервере в репозитории shared-services (docker-compose.yml) и делятся между front-office-pro, agentic-rag и deep-hire через сеть shared-services-net. Сам deep-hire поднимает в своём docker-compose.yml только backend/frontend/nginx, а к остальному подключается через host.docker.internal.
